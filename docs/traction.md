# Traction experiment

Start: 2026-10-13. First review: 2026-10-27. This date is a manual checkpoint; no automatic collection or promotion has been configured.

## Question

Does a source-backed comparison help developers and agents choose a movement implementation for a constrained target more reliably or quickly than ordinary search?

## What counts

| Signal | Interpretation |
| --- | --- |
| Stars, views, clones | Interest/exposure; traffic can include bots and repeat visitors |
| A use-case issue with a target and specific outcome | Reported human use; self-report, not independent verification |
| An external correction or contribution | Engagement with the evidence |
| Paired agent trials | Measured decision quality and investigation effort |
| Revenue | Not measured; this pilot has no paid offer |

At launch, no external use, contribution, comparative performance or revenue has been established. Record observations with dates and links; do not turn crawler requests into adoption.

## Continue gate

The proposed gate for expansion is **three substantive use reports from distinct external people** and **one external correction/contribution**, plus paired trials showing the comparison catches material incompatibilities missed by ordinary search or reduces median investigation time by at least 25% without reducing answer quality.

This is a decision threshold, not a prediction. If exposure is too low, record the test as inconclusive. If people find it but report no useful difference, keep the seed small or contribute the useful records upstream. A star threshold alone does not open the gate.
